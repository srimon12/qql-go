## 2023-11-20 - Fast String Lookups in Lexer
**Learning:** In string processing (like the lexer), map lookups `keywords[string(buf)]` allocate if not structured perfectly. However, the existing implementation avoided allocations by using fixed-size byte buffers and exact matching for strings <= 16 bytes. But generating a switch statement on string length and first character (`lookupKeywordFast`) is still substantially faster (~2.5-3x faster for short strings, ~500x faster for strings missing the map that are long) because it avoids iterating over strings or memory completely for length/prefix mismatches and maps down to simple assembly jump tables.
**Action:** Use code generation to build optimized switch statements for hot-path static string lookups (like lexer keywords) instead of map lookups or loops.
