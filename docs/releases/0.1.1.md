# qql-go 0.1.1

Release date: 2026-04-14

## Summary

This release follows `0.1.0` with packaging and release-flow cleanup so the published CLI name, docs, and GitHub automation are consistent.

## Highlights

- Renamed the shipped binary to `qql-go` across Windows, Linux, and macOS release assets.
- Updated the CLI command surface and docs to use `qql-go` consistently.
- Updated skill helper scripts and examples to look for `qql-go` by default.
- Made the GitHub release workflow safe to rerun by updating existing releases instead of failing on duplicate tags.

## Known limits

- Text inference paths still depend on Qdrant Cloud in this Go build.
- Local or self-hosted Qdrant is still best for non-inference operations.
